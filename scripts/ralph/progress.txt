# Ralph Progress Log

## Codebase Patterns

- Singleton em todo pacote de infra/subdomínio: função pura `Connect(...)` +
  `sync.Once` com `InitX/Get/Close`; testes usam a função pura direto, nunca o
  singleton. Para testar ciclo do singleton, um único teste por pacote.
- Fail-closed do orgctx via `gorm.DB.AddError`: contexto sem escopo devolve
  query que FALHA na execução (`ErrEscopoAusente`) — testado com gorm DryRun
  sem banco real.
- Testes que dependem de docker/testcontainers: helper `dockerDisponivel(t)`
  + `t.Skip` — verdes sem ambiente, reais com ele (postgres:16 local).
- Config/jwt singletons precisam de `ResetarParaTeste()` exportado quando
  outros pacotes exercem o boot nos próprios testes (`sync.Once` é por
  processo).
- CLI cobra imprime via `cmd.OutOrStdout()` (nunca os.Stdout) para saída
  testável; comandos montados por funções construtoras sem estado global.
- swag/arch-go instaláveis no Go 1.25: arch-go mudou para
  `github.com/arch-go/arch-go`; usar `swag@latest` (v1.16.6 fixa x/tools
  antigo que não compila).
- Regra arch-go do `cmd` precisa listar `workspace-api/cmd` além de
  `internal` — bootstrap/server/cli se importam entre si por design.
- Dublês de contrato que o service consome com ctx escopado precisam EMULAR
  o fail-closed do orgctx (org divergente = não encontra) — senão o teste
  valida um comportamento que não existe.
- `rest_err.RegistrarCatalogo` PANICA com code duplicado: nunca mapeie duas
  sentinelas para o mesmo `Codigo` no errors.go — cada uma tem code próprio
  (mesmo status/mensagem podem repetir).
- Seed pela CLI exige `migrate up` antes (o CLI não migra sozinho);
  `migrate down N` recebe N POSICIONAL, sem flag.
- Todo caminho interno do service que grava/consulta por repositório
  escopado precisa do MESMO ctx escopado — repassar o ctx "cru" para uma
  chamada interna quebra fail-closed silenciosamente (virou 500 no smoke).
- Cobertura Swagger executável: bootar os singletons UMA vez por pacote de
  teste sobre postgres efêmero, montar o engine real e comparar
  engine.Routes() × docs/swagger.json nos dois sentidos (normalizar `:p` →
  `{p}`; excluir /api/status, /doc, /doc/*qualquer).
- Conferência do grafo de dependências como gate: `go list -json ./...` +
  classificação por camada no teste raiz reprova aresta proibida do doc 01
  sem depender de ferramenta GUI.
- `go test -race` precisa de CGO+gcc no ambiente (apt-get install gcc;
  CGO_ENABLED=1) — invariantes disputadas rodam localmente desde a F6.
